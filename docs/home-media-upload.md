# Homepage media slots

The homepage is ready for three muted, looping MP4 clips. Put the exported Seedance files in `static/media/research/` with these exact names:

1. `world-sensing.mp4` — open-world sensing
2. `human-interaction.mp4` — human understanding
3. `mobile-manipulation.mp4` — long-horizon mobile manipulation

Recommended export:

- 16:9
- 6–8 seconds
- H.264 MP4
- 24 or 30 fps
- 1920×1080 or 1280×720
- no audio
- first and last frames close enough to loop cleanly

The page already has image posters, so it will continue to show a real image until the corresponding MP4 is added. Once a file is placed at the expected path, the template automatically uses the video.
