# PAIRS Lab member-profile template

This is the information sheet to collect before building member-level pages. Keep every profile consistent; optional fields can be left blank.

## Recommended page structure

1. **Identity block**
   - Full name
   - Preferred name
   - Role: PhD student / MPhil student / research assistant / visiting student
   - Start year
   - Portrait (square or 4:5, neutral background)
   - One-sentence research line

2. **Contact block**
   - Institutional email
   - Personal website
   - Google Scholar
   - GitHub
   - ORCID (optional)

3. **Research block**
   - 3–5 research-interest tags
   - 60–100 word biography
   - Current research direction
   - Methods, sensors, or platforms used

4. **Selected work**
   - Up to 3 projects or publications
   - One-line contribution for each
   - Paper / project / code links when available
   - Project image or short demo video (optional)

5. **Background**
   - Education: degree, institution, year
   - Previous experience (optional)
   - Awards or service (optional)

## Suggested visual template

Use a restrained two-column academic profile:

- Left: portrait, role, email, website, and external links.
- Right: name, one-line research statement, short biography, research-interest tags.
- Lower section: selected work as a compact list with one thumbnail per item.
- On mobile: stack the portrait/contact block above the biography and work.

This follows the useful parts of the reference styles without copying their branding: a clear identity block, compact contact links, and a research-first content hierarchy.

## Reference pages to review

- [ENVISION Lab people directory](https://envision-research.hkust-gz.edu.cn/people-page.html) — useful for a compact lab-wide directory and role grouping.
- [CMU Robotics Institute people directory](https://www.ri.cmu.edu/people/) — useful for consistent member cards and individual profile entry points.
- [ETH Autonomous Systems Lab people page](https://asl.ethz.ch/the-lab/people.html) — useful for separating group roles while keeping a restrained academic layout.

## Collection rules

- Use English throughout the site.
- Do not invent a personal website; leave the field blank when unavailable.
- Use one recent portrait per person and keep the crop consistent.
- Keep bios factual and concise; avoid CV-length paragraphs.
- Only list work that the member is comfortable showing publicly.
